How it works

  1. Generate synthetic GL and bank datasets with injected errors (seeded, so results are repeatable).
  2. Match records on reference ID; compare amounts against the tolerance.
  3. Classify breaks: amount mismatch, missing in GL, missing in bank, duplicate posting.
  4. Rank exceptions by absolute variance and attach a rule-based likely cause for reviewer triage.

Every flag needs human review. Stack: JavaScript here; the same logic maps to Python (pandas) and SQL joins. Replace the generator with real extracts to use it on live data.
